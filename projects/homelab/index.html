My old high school laptop - formerly on Windows 7, now running Ubuntu. Acts as the central "brain" of the lab and a way to practice my Linux fluency. I swapped the old spinning disk for an SSD and dropped in some extra RAM (upgrading a Lenovo feels like snapping Legos together). It also has a built-in SD card slot, making it an ideal station for imaging new Raspberry PI experiments.

A custom-upgraded HP Z240 rescued from tech-trash recycling, running TrueNAS OS. Features 2x 2TB spinning drives, mirrored for redundancy. Not a ton of space, but storage is expensive these days. It's still enough to hold my music library!

The infamous "Trash Can" served as my main college computer and beyond. It still chugs along on MacOS 12 - the plan is to convert this into a Jellyfin server.

Four different models of Raspberry Pi means a varied set of platforms for all sorts of experiments.

  1. CleavePi Alpha - Raspberry Pi 5, currently running Home Assistant
  2. CleavePi Bravo - Raspberry Pi 4, PoE-capable - currently running Pi-hole DNS. Planned project: Tailscale subnet router.
  3. CleavePi Charlie - Raspberry Pi Zero W - WiFi-capable - currently running Kiwix Serve as an off-grid Wikipedia server
  4. CleavePi Delta - Raspberry Pi Zero - planned project: houseplant soil sensor station
